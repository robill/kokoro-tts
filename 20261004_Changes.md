# Changes — 4 October 2026

## Simplified study EPUB export

- Added an optional exporter that applies validated, reviewed Chinese
  preprocessing caches to a copy of the bilingual EPUB.
- Preserved the source EPUB, English paragraphs, Chinese chapter headings,
  unselected chapters, ZIP member order, and package metadata.
- Added cache/source digest and paragraph-alignment checks, XHTML markup
  safeguards, destination overwrite protection, atomic output, and final ZIP
  integrity verification.
- Documented one-chapter export and full-range behavior in the README.
- Added an optional end-of-chapter vocabulary appendix with Hanzi, tone-marked
  Pinyin, and English meanings; no vocabulary is spoken as part of the chapter
  audio.
- Preserved Calibre reading bookmarks when refreshing an existing study EPUB.
- Added optional Chapter TTS vocabulary playback after narration. Speak Hanzi
  with Misaki G2P and English meanings with the English voice; do not speak
  Pinyin.
- Added a strict, no-reencode merger for numbered per-chapter MP3s into one
  validated audiobook file.
- Added a Windows Command Prompt batch runner for the complete RMJI workflow,
  including cache reuse, a manual review pause, vocabulary audio, study EPUB,
  and single-file audiobook merge.
- Generalized the Windows runner to accept another prepared bilingual EPUB and
  chapter range, and added a project-scoped Copilot skill covering EPUB
  preparation/splitting, paired-chapter preconditions, review gates, TTS, and
  validation. Kept the RMJI launcher as a thin wrapper.
- Added a pinned bilingual-audio Python dependency lock and Windows bootstrap
  that installs exactly one CPU/GPU ONNX Runtime, downloads and SHA-256 checks
  all four model/voice assets, and smoke-tests both synthesis paths.
