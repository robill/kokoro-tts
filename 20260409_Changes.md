# Changes - April 9, 2026

## Summary
Fixed EPUB manifest corruption issues in TGR Chapter EPUB files and created an automated repair script.

## Issues Encountered

### TGR Chapter 0001-0050.epub Processing Failure
- **Error**: `KeyError: "There is no item named 'OEBPS/Images/arrow_medium.png' in the archive"`
- **Root Cause**: The manifest file `content.opf` referenced three image files that don't exist in the EPUB archive:
  - `OEBPS/Images/arrow_medium.png`
  - `OEBPS/Images/bullet_blue.png`
  - `OEBPS/Images/hr.png`
- **Impact**: All TGR EPUB files with similar corruption couldn't be processed by the TTS converter

## Resolution

### Manual Fix (Initial)
1. Extracted the corrupted EPUB to a temporary directory
2. Parsed the `content.opf` XML manifest file
3. Removed the three missing image item references from the manifest
4. Repackaged the EPUB file

### Automated Solution (Initial)
Created `fix_epub_manifests.ps1` - a PowerShell script that:
- Automatically detects all `TGR*.epub` files in the directory
- Extracts each EPUB to a temporary directory
- Scans the manifest for image references
- Identifies missing image files by checking disk existence
- Removes broken manifest entries
- Repackages the EPUB with the corrected manifest
- Creates backups and restores them if errors occur
- Cleans up temporary files

**Initial Issue**: First version had XML namespace handling problems - XPath queries weren't finding the items due to namespace not being handled in the manifest parsing.

### Script Fix & Final Solution
Updated `fix_epub_manifests.ps1` with proper namespace handling:
- Added `XmlNamespaceManager` to handle the `http://www.idpf.org/2007/opf` namespace
- Changed from attribute property access to `GetAttribute()` method
- Fixed pattern matching from `-contains` to `-like` for proper string comparison
- Now correctly identifies ALL missing image references across all files

## New Files Added

## Usage
```powershell
# Fix all TGR*.epub files (default)
.\fix_epub_manifests.ps1

# Fix WDQK*.epub files
.\fix_epub_manifests.ps1 -Pattern "WDQK*.epub"

# Fix Stellar Transformations files
.\fix_epub_manifests.ps1 -Pattern "STB*.epub"

# Fix any pattern
.\fix_epub_manifests.ps1 -Pattern "*.epub"
```

## Script Features
- **Configurable pattern matching**: Use `-Pattern` parameter to process any EPUB file pattern
- **Namespace-aware XML parsing**: Properly handles EPUB manifest namespaces
- **Selective removal**: Only removes missing image references, leaves valid ones intact
- **Safe operations**: Creates backups and restores on error
- **Automatic cleanup**: Removes temporary files after processing

## Technical Notes
- EPUB files are ZIP archives containing XML metadata
- The `content.opf` file in META-INF or at root level contains the manifest that lists all resources
- Entries in the manifest must reference files that actually exist in the archive
- This corruption likely occurred during EPUB creation/splitting process
- **XML Namespace Handling**: EPUB manifests use the `http://www.idpf.org/2007/opf` namespace, requiring `XmlNamespaceManager` for proper XPath queries
- Direct XPath queries without namespace awareness fail to find elements in namespaced XML documents
